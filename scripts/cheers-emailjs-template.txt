====================================================
  Cheers.co — EmailJS 新订单通知模板
====================================================

在 EmailJS 后台 (https://dashboard.emailjs.com) 创建一个新模板，
将以下内容复制进去。模板参数用 {{变量名}} 表示。

----------------------------------------------------
Subject（邮件标题）：
----------------------------------------------------
【Cheers.co 新订单】{{order_id}}

----------------------------------------------------
Body（邮件内容）：
----------------------------------------------------
您有一笔新订单！

订单号：{{order_id}}
下单时间：{{order_date}}

顾客姓名：{{customer_name}}
顾客邮箱：{{customer_email}}
顾客电话：{{customer_phone}}

商品列表：
{{order_items}}

配送方式：{{delivery_info}}

订单总额：{{order_total}}

----------------------------------------------------
EmailJS 模板设置说明：
----------------------------------------------------
1. To Email：填写 {{to_email}}（系统会自动使用管理员联系设置中的邮箱）
2. From Name：Cheers.co
3. Reply To：{{customer_email}}
4. 创建完成后将 Template ID 填入 Admin → 联系方式 → EmailJS Template ID

模板参数列表（供参考）：
- to_email         收件邮箱（管理员）
- order_id         订单号，例：CHEERS-20260504-1234
- customer_name    顾客姓名
- customer_email   顾客邮箱
- customer_phone   顾客电话
- order_items      商品列表（多行文字）
- order_total      订单总额，例：RM 88.00
- delivery_info    配送方式，例：邮寄 · 西马 · 47500 Subang Jaya, Selangor
- order_date       下单时间
