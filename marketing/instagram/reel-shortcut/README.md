# JSave screenshot import Reel

Vertical Instagram Reel built from two real iPhone demonstrations: a screenshot automation and a Photos share-sheet import. The finished video is `jsave-shortcut-demo.mp4` (1080 × 1920, 30 fps, 11.5 seconds).

Published on the JSave Instagram account: https://www.instagram.com/j._save/reel/Dds2ntvRMya/

When uploading through Instagram's desktop composer, choose **9:16** in the Crop menu. The default 1:1 crop truncates the top and bottom of this video. The earlier Reel with the duplicated category step was removed after this edit was verified.

| Time | Scene | Message |
| --- | --- | --- |
| 0.0–1.5s | Brand opening | Aiyo, 又忘记记账？ |
| 1.5–3.0s | Screenshot automation | A screenshot can start the shortcut |
| 3.0–4.7s | Photos share sheet | Or share from Photos |
| 4.7–6.3s | Category choice | Choose a category once |
| 6.3–8.3s | Review | Check before saving |
| 8.3–9.7s | Completion | Saved; option to delete the photo |
| 9.7–11.5s | Brand closing | Install from JSave settings |

The source recordings are private and are not included here. The automation screenshot is blurred in full. The other clips crop away unrelated photos, account information, receipt IDs and barcodes. The category clip ends before the menu closes and reveals the receipt below it. Opaque boxes cover the real amount, date and merchant in the review scene. The original recording audio is not used; the soundtrack is generated by the build script.

The shortcut extracts text on iPhone and sends that text to JSave for parsing; the screenshot itself stays on the phone. The Reel shows the adapted TNG and CIMB single-transaction import flow. It does not claim to support every bank screenshot or full statements.

`reel-cards.html` and `stages.html` contain editable visual layouts. `render-cards.mjs` and `render-stages.mjs` export their JPEG frames. To rebuild the video after preparing those frames, install `ffmpeg-static` or provide `FFMPEG_PATH`, then run:

```powershell
node marketing/instagram/reel-shortcut/build-reel.mjs <automation-recording.mp4> <album-recording.mp4>
```

The source video files must remain private. Review the complete output for visible personal or financial details before publishing a new edit.
