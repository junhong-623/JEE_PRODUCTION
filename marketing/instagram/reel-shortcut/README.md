# JSave screenshot import Reel

Vertical Instagram Reel built from two real iPhone demonstrations: a screenshot automation and a Photos share-sheet import. The finished video is `jsave-shortcut-demo.mp4` (1080 × 1920, 30 fps, 15.9 seconds).

Published on the JSave Instagram account: https://www.instagram.com/j._save/reel/DdsSWVtRLlP/

| Time | Scene | Message |
| --- | --- | --- |
| 0.0–2.3s | Brand opening | 付款截图，怎样进入 JSave？ |
| 2.3–4.1s | Screenshot automation | Screenshot runs the unified shortcut |
| 4.1–6.6s | Photos share sheet | Select JSave-Receipt-Import |
| 6.6–8.6s | Category choice | Choose a category |
| 8.6–11.1s | Review | Check before saving |
| 11.1–13.1s | Completion | Saved; option to delete the photo |
| 13.1–15.9s | Brand closing | Install from JSave settings |

The source recordings are private and are not included here. The video crops away unrelated photos, account information, receipt IDs and barcodes. Opaque boxes cover the real amount, date and merchant in the review scene. The original recording audio is not used; the soundtrack is generated by the build script.

The shortcut extracts text on iPhone and sends that text to JSave for parsing; the screenshot itself stays on the phone. The Reel shows the adapted TNG and CIMB single-transaction import flow. It does not claim to support every bank screenshot or full statements.

`reel-cards.html` and `stages.html` contain editable visual layouts. `render-cards.mjs` and `render-stages.mjs` export their JPEG frames. To rebuild the video after preparing those frames, install `ffmpeg-static` or provide `FFMPEG_PATH`, then run:

```powershell
node marketing/instagram/reel-shortcut/build-reel.mjs <automation-recording.mp4> <album-recording.mp4>
```

The source video files must remain private. Review the complete output for visible personal or financial details before publishing a new edit.
