# JSave 统一收据截图 iPhone 快捷指令

一个已签名的 iPhone 快捷指令负责提取截图文字、显示类别菜单和确认提醒。JSave 的受保护接口根据文字识别来源并选择解析规则。目前支持 TNG 与 CIMB 交易详情截图；将来新增 Maybank 或其他银行时，在 JSave 增加解析规则与账户选项即可沿用同一个手机指令。

## 安装

1. 在 JSave「设置 → 账户」建立自己使用的 TNG 钱包、CIMB 银行及 CIMB 信用卡账户。未使用的来源可以不建。
2. 在「设置 → 统一收据截图快捷指令」选择对应账户。CIMB 向自己的 TNG 钱包充值需要同时设置 CIMB 银行和 TNG 钱包。
3. 点「生成统一密钥」并复制。密钥只显示一次；截图内容会以文字形式提交到 JSave 接口，图片本身不上传。
4. [下载 `JSave-Receipt-Import.shortcut`](../public-jsave/shortcuts/JSave-Receipt-Import.shortcut)，在 iPhone 的「文件」App 打开并填入密钥。若没有出现导入提问，编辑 `JSave Receipt Import`，把密钥填入第一个「文本」操作。
5. 从「照片」分享一张 TNG 或 CIMB 交易截图给这个指令。核对来源、账户、金额、日期、说明和类别后，再确认保存。

签名文件 SHA-256：`3B4BECFAF9B72AF1A028718B58097CE1646FC7A058D85DB7BEC88CC0577702D9`。

已安装的旧 TNG 和 CIMB 指令可以暂时保留。统一指令使用独立密钥；旧指令与旧密钥不会自动失效。旧版下载与设置入口已撤下，统一指令实机测试通过后，可以从 iPhone 移除旧指令。如需停用旧版密钥，需要通过旧版管理接口处理。旧版与新版沿用同一来源交易编号去重，避免同一张截图因换指令重复入账。

## 后续新增银行

统一指令只提交 OCR 文字和使用者选定的类别，不内置银行解析规则。新增银行时，JSave 端需增加格式识别、对应账户选项及测试；原有指令和密钥继续使用。账户设置可以单独保存，无需重新生成密钥。若多家银行的截图格式无法可靠区分，接口可返回来源选项，由同一指令请使用者选择。

## 限制

- 当前只支持已验证的 TNG 和 CIMB 页面格式。Maybank 以及其他银行还未加入识别规则，不能直接导入。
- 每次处理一张截图，不处理整份 PDF statement。
- CIMB 截图没有稳定的交易编号，同一天同金额且说明相同的两笔交易可能被当成重复。
- CIMB 的 TNG 充值记为账户间转账；若也导入 TNG 钱包内对应的入账截图，请核对，避免重复计算。
- 安装、iPhone OCR 与删除照片需在手机上实机验证。非已支持格式会静默结束；字段不足的支持格式会显示错误，不保存交易。
