# 旧版 JSave × CIMB 快捷指令（已停用）

旧版 CIMB 的导入接口和密钥管理接口已停用。已经安装的 `JSave CIMB Import` 无法继续导入交易；旧密钥也不适用于统一版。

请改用[统一收据截图快捷指令](jsave-receipt-shortcut.zh.md)，在 JSave 设置中选择对应的 CIMB 账户并生成统一密钥。确认统一版可用后，可以从 iPhone 删除旧指令。

旧版 Cherri 源码仍保留在 [`shortcuts/JSave-CIMB-Import.cherri`](../shortcuts/JSave-CIMB-Import.cherri)，仅供历史参考。已经保存的交易不会因旧接口停用而删除。
